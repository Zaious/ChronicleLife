# ChronicleLife — 視覺設計規範

風格沿用 Basesmall / SmalLoL(同為 ChronicleCore Studio 的桌面小工具):安靜、瞄一眼就懂、文字一律坐在膠囊上。
Token 的唯一定義處:[`src/lib/core/theme.ts`](../src/lib/core/theme.ts);共用控制項樣式:[`src/app.css`](../src/app.css)。

## 原則

1. **安靜。** 平常只看得到資料。控制列在 hover、鍵盤聚焦、或面板開著時才出現;動畫單發且短,不循環(「閃爍效果」是使用者自己開的選項)。
2. **文字坐在膠囊上。** 每個時間軸列是一顆膠囊,不論桌布或網頁背景都讀得清。視窗越透明膠囊越實(`capsuleAlpha`),文字背後的總不透明度恆 ≥ 0.88。不得再用文字陰影、逐標籤色塊這類補丁。
3. **膠囊就是時間視窗。** 膠囊內的空間 = 整段時間視窗(預設 30 天),彩色條是還剩下的部分;條越短、膠囊越空,不另畫刻度。
4. **單一強調色。** 琥珀色只用在「下一件」、倒數時間、勾選與主按鈕;逾期與到期的檢查點用 `--strike`。分類色是資料色,不拿來當介面色。
5. **不用原生元件。** 下拉選單、色盤改用分段控制(`.seg`)、分類籤(`.chip`)與內建色票。原生色盤在透明視窗上會讓 WebView2 崩潰(見 `ColorPicker.svelte`);日期與時間欄位仍用原生 `<input>`,以 `color-scheme` 跟著主題。

## Token

| token | 深色 | 淺色 | 用途 |
| --- | --- | --- | --- |
| `--background` | `#15171C` | `#F2F3F6` | 視窗底、面板底 |
| `--panel` | `#1B1E24` | `#FFFFFF` | 膠囊、輸入框、卡片 |
| `--border` | `#2A2E37` | `#D5D9E1` | 邊框、分段控制的選中底 |
| `--text` / `--muted` | `#E8EAEE` / `#A0A6B1` | `#1B1E24` / `#5A6272` | 主要 / 次要文字 |
| `--accent` | `#E8B04A` | `#9A6200` | 強調文字與控制項(滑桿、勾選) |
| `--accent-fill` | `#E8B04A` | `#D99A1E` | 強調填色(「下一件」底色與外框、主按鈕邊框) |
| `--strike` | `#D9643F` | `#BF3F0F` | 逾期、到期檢查點、危險操作 |

字體:`'Segoe UI Variable', 'Segoe UI', 'Microsoft JhengHei UI', 'PingFang TC', system-ui`;數字與日期用 `'Cascadia Mono', Consolas`。

## 共用控制項

`.field`(輸入框)、`.btn`(`.primary` 琥珀外框、`.danger`)、`.icon-btn`(24×24 熱區、14px 圖示)、`.seg`(分段控制)、`.chip`(分類籤)、`.check`、`.h`(區塊標題)、`.error`;
動畫 `cl-rise`(進場)、`cl-glow`(單發光暈)、`cl-turn`(閃爍效果)。減少動態偏好時一律降為瞬間。

需要新控制項時先看 `src/app.css` 有沒有;沒有就加在那裡,不要寫進單一元件的 `<style>`。

## 對比驗收(由 `theme.test.ts` 強制,深淺兩套都要過)

- 文字、次要文字對膠囊底與視窗底:≥ 4.5、≥ 3。
- 強調色、逾期色當文字用,對膠囊底與視窗底:≥ 4.5。
- 任何視窗不透明度下,文字背後的總不透明度 ≥ 0.88。
